# Tower Images Instructions

## 📸 Where to Save Tower Images:

Save your tower images in the following directory:
`assets/images/towers/`

## 🏗️ Required Image Files:

1. **tower1.jpg** - Image of Tower 1
2. **tower2.jpg** - Image of Tower 2  
3. **tower3.jpg** - Image of Tower 3
4. **faculty_tower4.jpg** - Image of Faculty Tower 4

## 📏 Recommended Image Specifications:

- **Format**: JPG or PNG
- **Resolution**: 800x600 pixels or higher
- **Aspect Ratio**: 4:3 or 16:9
- **File Size**: Keep under 2MB each for optimal app performance

## 📱 How Images Will Appear:

- Tower images will be displayed as cards on the main institutional map page
- Each tower card will show the image with the tower name overlay
- Images will have rounded corners and shadow effects
- Fallback icons will show if images are not available

## 🎨 Placeholder Images:

If you don't have tower images yet, the app will show building icons as placeholders. Once you add the actual images with the correct names, they will automatically appear in the app.
