# MIST Academic Programs and Curriculum

## Computer Science and Engineering (CSE)

### Program Overview
The CSE program at MIST is designed to produce skilled software engineers and computer scientists capable of addressing the technological challenges of the modern world.

### Curriculum Highlights
- Programming Languages: C, C++, Java, Python, JavaScript
- Data Structures and Algorithms
- Database Management Systems
- Software Engineering
- Computer Networks
- Artificial Intelligence and Machine Learning
- Web Development
- Mobile Application Development
- Cybersecurity
- Computer Graphics

### Career Opportunities
- Software Developer
- System Analyst
- Network Administrator
- Database Administrator
- AI/ML Engineer
- Cybersecurity Specialist
- Research Scientist

## Electrical, Electronic and Communication Engineering (EECE)

### Program Overview
EECE program focuses on electrical systems, electronics, and communication technologies.

### Curriculum Highlights
- Circuit Analysis
- Digital Electronics
- Microprocessors and Microcontrollers
- Communication Systems
- Signal Processing
- Power Systems
- Control Systems
- VLSI Design
- Embedded Systems

### Laboratories
- Electronics Lab
- Communication Lab
- Microprocessor Lab
- Power Systems Lab
- Control Systems Lab

## Mechanical Engineering (ME)

### Program Overview
ME program covers design, manufacturing, and maintenance of mechanical systems.

### Curriculum Highlights
- Thermodynamics
- Fluid Mechanics
- Heat Transfer
- Manufacturing Processes
- Machine Design
- Automotive Engineering
- Robotics and Automation
- Materials Science

### Facilities
- Manufacturing Lab
- Thermal Engineering Lab
- Fluid Mechanics Lab
- CAD/CAM Lab
